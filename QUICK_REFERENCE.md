## 📋 7 LAYANAN PERMOHONAN

### 1. 🔧 Sewa Alat (Equipment Rental)
**Dokumen:** KTP + Surat Permohonan  
**Status:** Belum Lunas → Siap Diambil → Dibawa → Dikembalikan  
**Waktu:** 2-5 hari  
**Catatan:** Untuk sewa peralatan diagnostik BMKG

### 2. 📚 Magang (Internship)
**Dokumen:** KTP + CV + Surat Rekomendasi  
**Status:** Menunggu → Ditinjau → Diproses → Selesai  
**Waktu:** 7-14 hari  
**Catatan:** Program magang di BMKG

### 3. 👥 Kunjungan (Site Visit)
**Dokumen:** Identitas + Surat Pengantar  
**Waktu:** 3-7 hari  
**Catatan:** Kunjungan ke fasilitas BMKG

### 4. 💰 Asuransi (Insurance Claim)
**Dokumen:** KTP + Bukti Kerugian + Foto  
**Waktu:** 5-10 hari  
**Catatan:** Klaim asuransi bencana alam/kesehatan

### 5. 💬 Konsultasi (Consultation)
**Dokumen:** Deskripsi masalah + Dokumen supporting  
**Waktu:** 2-7 hari  
**Catatan:** Konsultasi dengan ahli BMKG

### 6. 📋 Survey (Participation)
**Dokumen:** Minimal identitas  
**Waktu:** 1-3 hari  
**Catatan:** Partisipasi survey penelitian

### 7. 📊 Layanan Data (Data Request)
**Dokumen:** Spesifikasi + Tujuan + Proposal  
**Waktu:** 5-10 hari  
**Catatan:** Request data meteorologi/geofisika

## 📱 HOW TO: UPLOAD DOKUMEN

1. **Format File:**
   - ✅ PDF, JPG, PNG
   - ❌ Word, Excel, ZIP (tidak didukung)

2. **Ukuran:**
   - Minimal: 200 KB
   - Maksimal: 5 MB

3. **Kualitas:**
   - Harus jelas terbaca
   - Tidak blur/rusak
   - Warna: Berwarna (untuk KTP)

4. **Upload Process:**
   ```
   Klik "Pilih File" → Browse Komputer → Select → Upload ✅
   ```

5. **Troubleshooting:**
   - Gagal? → Cek ukuran & format
   - Slow? → Cek internet connection
   - Timeout? → Try lagi atau use diff device

## 🤖 CHATBOT QUICK TIPS

### Tipe Pertanyaan
- ✅ Tentang BMKG
- ✅ Tentang layanan
- ✅ Tentang meteorologi
- ✅ About akun
- ❌ Process real transaction
- ❌ Personal data inquiry

### Best Practices
1. **One question per chat**
   - ❌ "Siapa pendiri BMKG dan apa tugasnya?"
   - ✅ "Siapa pendiri BMKG?" (baru tanya tugas)

2. **Be specific**
   - ❌ "Bagaimana cara sewa?"
   - ✅ "Bagaimana cara sewa alat meteorologi dan berapa biayanya?"

3. **Use clear Indonesian**
   - ❌ "gmn cara login kak"
   - ✅ "Bagaimana cara login ke akun BMKG SOFTPRO?"

4. **Rate feedback**
   - Beri bintang untuk improve AI
   - 5⭐ = sangat membantu
   - 1⭐ = tidak membantu
